# Security policy

## Reporting a vulnerability

Please report it privately through GitHub, not in a public issue:

1. Open the affected repository's **Security** tab.
2. Choose **Report a vulnerability**.

Only the maintainers can see the report. You can discuss it with them there, and they can credit you when it's
fixed, if you'd like.

It helps to include:
- what's affected (the repository, and a commit or version);
- how to reproduce it;
- what an attacker could do with it.

## Supported versions

troupe is pre-alpha and has no releases yet. Reports about the `main` branch of any troupe-run repository are
welcome.
